# Candela Themes for Zed

Color themes for editors and terminals, tuned for long sessions and tired eyes. Low-glare backgrounds, desaturated accents, and WCAG-AA contrast throughout, with the same palette everywhere you work.

![Candela in Zed, light](https://raw.githubusercontent.com/schovi/candela-themes/main/docs/screenshots/zed/zed-light.png)

![Candela in Zed, dark](https://raw.githubusercontent.com/schovi/candela-themes/main/docs/screenshots/zed/zed-dark.png)

## Why Candela

- **Built for tired eyes** — low-glare backgrounds (never pure white or black) and desaturated accents that resist visual fringing.
- **Readable by design** — every syntax and UI color clears WCAG-AA contrast; primary text clears AAA.
- **One palette everywhere** — the same colors in your editor and your terminal.
- **A whole family** — light schemes for every room, plus dark companions, all from one coordinated, curated set.

Install from Zed: `zed: extensions` → search "Candela", then pick any *Candela …* entry
in the theme selector. Each theme colors the whole window — editor, sidebar, tabs,
status bar and integrated terminal — so nothing is left on Zed's default gray.

Build your own in the browser: adjust any palette, keep the same contrast rules, export it for your editor — [candela.ink/editor](https://candela.ink/editor).
